# Security Policy

## Educational Project Notice

> 🎓 **Notice:** This repository is an **educational laboratory demonstration suite** of NIST and FIPS cryptographic standards. It is designed for study, demonstration, and academic evaluation, NOT as an enterprise cryptographic production library.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security flaw or vulnerability (such as a cryptographic implementation bug or improper randomness handling):

1. **Do NOT open a public issue.**
2. Email **tahniatfarhan@gmail.com** with details on the vulnerability and steps to reproduce.
3. We will acknowledge receipt within 48 hours and issue a patch release.
